# نظام إدارة الموارد البشرية
## جمعية أصدقاء البيئة الفلسطينية

### المميزات الرئيسية:
- ✅ **نظام Workflow كامل** مع صلاحيات محددة لكل دور
- ✅ **تسجيل كل الحركات** (User + IP + Time)
- ✅ **إضافة موظف جديد** فقط بعد مقابلة + موافقة لجنة + موافقة المدير التنفيذي
- ✅ **رفع ملفات** (مقابلات، امتحانات، سيرة ذاتية، صورة هوية، مؤهلات)
- ✅ **سيرة ذاتية متقدمة** مع حساب تلقائي لـ:
  - إجمالي ساعات التدريب
  - سنوات الخبرة العملية
- ✅ دعم **أكثر من مؤهل علمي** لكل موظف
- ✅ بيانات كاملة حسب طلبك (18 حقل + أقسام ديناميكية)

### كيفية التشغيل:
```bash
cd /home/workdir/artifacts/hr_system
php -S localhost:8000
```
ثم افتح: **http://localhost:8000**

### سير العمل (Workflow):
1. **مسؤول الموارد البشرية** → يضيف بيانات الموظف + يرفع ملف المقابلة + يكتب ملاحظات
2. **لجنة المقابلات** → توافق أو ترفض
3. **المدير التنفيذي** → موافقة نهائية
4. بعد الموافقة النهائية → يصبح الموظف "نشط" وتظهر سيرته الذاتية الكاملة
